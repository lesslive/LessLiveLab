基于本地 Markdown 笔记与 AI 协作，帮助你梳理生活课题、沉淀个人实践，把经验转化为可交付的产品与故事，收获同频的人，构筑你的生活圈。

## ✍️ 使用方法

把你的生活告诉你的 AI 助手：正在推进的工作、兴趣、爱好、学习……不管多乱。最好还跟它说说你想要什么、喜欢什么、讨厌什么以及为什么……，AI 助手会协助你：
- **发现你的相对先进性**

    找出你真正热爱的、愿意投入的、通过打磨和积累能形成领先优势的那件事；

- **整理成一个行动计划**

    把你在不同领域的人和事，融合成一个值得他们关注并愿意参与进来的项目；

- **设计成可执行的任务**

    根据不同阶段设计行动策略，拆成具体做什么怎么做，推动进度并反馈结果；

- **生成对外发布的内容**

    围绕行动策略，针对发布渠道，设计发布内容，让人们就像在看一部连续剧；

- **沉淀为资产下次使用**

    把实践中的结论和成果，沉淀为个人资产，下次不用重复介绍，越用越懂你。


## ✨ 核心特色

### 🏛️ 三大课题｜个人生存与生活模型

基于阿德勒的课题分离与共同体感受，用服务设计思维，把生活解构为可以研究、设计、执行和复盘的三大课题：
- [第一课题](/第一课题/第一课题.md) ｜和自己相处｜运行内核
	- **职责**：记录自己的内在、立场与状态等自我认知，建立与外部世界的边界
	- **目标**：不迎合、不讨好、不被外界裹挟的自我

- [第二课题](/第二课题/第二课题.md) ｜和世界相处｜运行环境
	- **职责**：基于第一课题，设计行动策略、目标、计划，构建生存与生活环境
	- **目标**：低成本、少依赖的谋生策略和外部环境

- [第三课题](/第三课题/第三课题.md) ｜和他人相处｜运行实例
	- **职责**：基于前两个课题，在具体项目中形成面向他人的表达、交付与输出
	- **目标**：和一群人构筑烟火气与人情味的生活圈

### 🧰 五大工具｜普通人用的大厂方法

把非暴力沟通、英雄之旅、马斯洛需求以及 AARRR、OKR、SB7 等，改造成对普通人友好、拿来就能用的个人工具：
- [生活主义画布](/第二课题/能力/生活主义画布/生活主义画布.md)：用课题分离设计边界清晰的叙事，避免讨好迎合陷入内耗
- [内容运营三角](/第二课题/能力/内容运营三角/内容运营三角.md)：展示价值、汇报进度、提供服务，让输出内容饱满且精彩
- [第一人称法则](/第二课题/能力/第一人称法则/第一人称法则.md)：从我，到我和你，再到我们一起，让受众看一场人生电影
- [行动旅程看板](/第二课题/能力/行动旅程看板/行动旅程看板.md)：针对个人任务的目标与关键成果工具，让执行高效且有序
- [新马斯洛需求](/第二课题/能力/新马斯洛需求/新马斯洛需求.md)：判断行动计划所处的发展阶段，定义当前阶段的工作重点

### ⚙️ 三大原则｜为系统运行保驾护航

一套用于全局设计和运行的正交组合方法，从三个维度同时作用于生存与生活的方方面面：
- **结构化** ｜让生活井井有条
	- 将生活拆分为边界清晰且彼此关联的模块
	- 让每件事都有适合它的归属和精准的位置

- **最小化** ｜让自己轻装上阵
	- 移除那些消耗和拖累自己的复杂性和冗余
	- 只保留确实需要且只需要的最少必要条件

- **资产化** ｜把时间变成资产
	- 把实践中的方法和经验，沉淀为个人资产
	- 持续打磨并完善和迭代，积累成个人财富

## ⚡ 开始使用

```
git clone https://github.com/lesslive/LessLive.git 
```

克隆仓库到本地，接入可编辑本地文件的 AI Agent（如 Codex、WorkBuddy、豆包工作等），发送消息给 AI 助手，它会协助你：

1️⃣ **初始化**：整理真实现状、绘制蓝图、规划旅程、设计共同体项目，让模型具备运行条件

2️⃣ **运行时**：在真实生活中使用，并按需补全和完善其他组件和模块，用模型驱动真实生活

- **说明**：也可以自行阅读仓库文档内容，理解并应用，无需 AI 协助。
- **推荐**：使用 Obsidian 管理仓库，请参考作者的[插件清单](/系统服务/工具/Plugins-List.md)并选择安装与配置，获得更好的交互体验。
- **声明**：仓库中带 `example` 标签的文件是作者的真实实践，帮助你和 AI 助手更好地理解并实践 LessLive。示例内容仅供参考，不构成任何效果保证或专业建议，使用风险自负。

## 🌍 社区活动

LessLive 发起的一系列社会实验，欢迎你加入，和我们一起成为生活的研究员，在自己的生活里开展：

- **把朋友圈变成生活圈**
 
    把你的生活变成人们愿意追更的故事，看看能不能收获真正懂你、滋养你的朋友和伙伴，慢慢形成你的生活圈。

- **帮助长辈重新被需要**
 
    用 AI 和现代化技术与工具，把长辈的本事做成对他人有用的东西，看看能不能帮长辈重新被需要，同时也让年轻的你找到方向。

- **把家乡特产卖给同学**

    上大学，除了学习知识，还可以利用闲暇时间，让家乡的特产走出大山，让自己先人一步踏入社会，毕业时，除了一张学历证书，看看能否还获得一份事业，打破毕业即失业的传说。
