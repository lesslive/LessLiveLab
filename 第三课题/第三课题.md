# 与他人相处
把人际关系作为研究对象，让推进的项目成为可以和不同受众共创和协作的共同体。
**运行实例：我和你之间的那件事，构建由高质量人际关系形成的生活圈。**

---
## 目标
- 把项目打造成和受众共同关注并愿意投入精力的话题；
- 将话题转化为项目发展的连续性事件形成完整的故事；
- 构建以个人为中心的社会关系，形成个人常态化生活。

---
## 结构

> [!multi-column] 
>
>> [!info] **价值** ｜我想表达什么
>> 
>> 1️⃣ 关注什么领域和问题、如何看待、持什么观点、立场与主张
>> 
>> 2️⃣ 发现并揭示被忽视的规律与方法，建立价值认同与同频共鸣
>> 
> 
>> [!info] **进度** ｜我正在做什么
>> 
>> 1️⃣ 我如何推进、遇到了什么、作了什么选择、产生了哪些变化
>> 
>> 2️⃣ 呈现我、项目、以及我和受众的关系逐步加深的连续性过程
> 
>> [!info] **服务** ｜能为你做什么
>> 
>> 1️⃣ 如何回应他人的需要，建立双向链接、参与互动的协作机制
>> 
>> 2️⃣ 活跃度衡量归属感，分享率体现自豪感，成交率反映价值感

## 说明

- **核心定位**：围绕具体项目（运行实例），解决我与他人如何表达、协作与建立关系（涵盖用户、伙伴、供应商及家人等）；项目承载谋生、交友、兴趣或公益等意图，方向与边界由第二课题确定。
- **三元表达结构**：以**价值**（主张与判断）、**进度**（真实实践与变化）、**服务**（回应需要与交付帮助）组织内容。三者按主要职能划分，非互斥标签；是否公开发布视具体成果而定。
- **一切产品皆服务**：产品是人服务人的工具与交付形态，统一归入**服务**模块（如训练营、活动、课程、书籍等），不单设第四模块；连续性产品及派生形态（如由课程衍生的视频脚本）须在对应目录维护完整交付正文，不以素材链接替代。
- **单一数据源（SSOT）**：全仓皆为表达素材库，第三课题只存加工后的成品并链接来源，不复制原文正文；每篇主题须能独立成立，可设阅读路径，不强行编造因果连载。

---
> [!ai]- AI 辅助
> - **先定职能再创作**：动笔前先与用户对齐本次表达的目的及主要职能（价值、进度或服务），依据已确认的蓝图、旅程与真实资料创作，不凭标题臆断背景。
> - **严守事实与结构边界**：引用全仓素材时维护单一数据源，严格区分已发生事实、个人判断与待验证假设，不把构想写成结果；单篇须能独立成立，不强行编造“下回分解”。
> - **守住权限与隐私红线**：不越权替代第二课题修改策略与目标；涉及敏感信息、个人真实经历或他人隐私时，严格遵循隐私规则并交由用户决定公开边界；关键信息不足时先提问，不自行脑补。
